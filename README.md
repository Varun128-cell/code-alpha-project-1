# 💬 AI Chatbot with Randomized Answers

A lightweight, fun AI chatbot that answers user questions using a pre-trained question-answering model and Wikipedia search — with a twist! If the answer isn't clear, it can give a randomized or humorous fallback response to keep the conversation going.

## 🤖 Features

- 🧠 Uses Hugging Face's Transformers for question answering
- 🌐 Pulls context dynamically from Wikipedia
- 🎲 Provides random or default replies when unsure
- 🖥️ Console-based interactive chat
- ✅ Simple and fast — perfect for demos or learning
